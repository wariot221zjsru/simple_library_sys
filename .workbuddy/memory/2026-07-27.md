# 2026-07-27 工作日志

## 图书管理系统 PyQt 图形界面开发

### 任务
在原有 CLI 图书管理系统基础上，新增 PyQt5 图形界面，将所有命令行功能用 GUI 实现。

### 完成内容
1. **新建文件 `library_gui.py`** —— 完整的 PyQt5 GUI 程序，约 580 行
   - 复用原有模块：`config.py`（分页配置）、`file_handler.py`（数据加载/保存）、`utils.py`（makePage 分页逻辑）
   - 不改动原有 CLI 程序文件任何内容
   - 从 CLI 中提取 `find_indices_by_keys` 等函数逻辑到 GUI 文件中（因 CLI 文件含 while 循环无法直接 import）

2. **GUI 功能覆盖**
   - Tab 1 图书管理：新增（对话框表单）、查看全部（表格 + 分页翻页：首屏2条/后续5条，与 CLI 一致）、查询（多字段模糊搜索取交集）、修改（选中行编辑）、删除（二次确认）
   - Tab 2 借阅管理：借出（输入书名/ISBN+借阅人）、归还（列表选择未归还记录）、记录查询（全部/未归还/已归还筛选）
   - Tab 3 数据统计：总览卡片（种数/总册数/在借数）、分类统计表格（区分实体册数与图书种数，含合计行）、逾期提醒表格（30天周期）

3. **关键设计决策**
   - 分类统计"实体册数" = 库存数量 + 在借数量（总物理册数），"种数" = 该分类下图书条目数
   - 借阅记录兼容 "已借出" 和 "borrowed" 两种状态写法（原数据不一致）
   - 使用 safe_int() 兼容原 CLI 中可能残留的字符串型库存数量
   - 每次操作后自动 save_data 保存到 JSON
